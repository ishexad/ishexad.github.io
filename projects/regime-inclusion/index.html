Does regime type shape women's labour force participation?

An interactive explorer comparing female labour force participation against regime type across 19 countries — the same kind of multi-country insight work behind Oxfam's Gender Justice Team evaluations and the Women Entrepreneurship Development project. Filter by region, sort the table, hover a country for detail.

Loading Regime types are V-Dem's 2024/25 Regimes of the World classification (sourced this session; see Methodology below). Fetching live female labour force participation from the World Bank API — falling back to a cached reference snapshot if that request fails or is blocked.

Methodology

Where the numbers come from.

Regime type follows the V-Dem Institute's four-category Regimes of the World typology (Closed Autocracy, Electoral Autocracy, Electoral Democracy, Liberal Democracy), based on the classifications reported in V-Dem's 2024–2026 Democracy Reports — including two 2024 revisions worth noting: Canada sits in Electoral rather than Liberal Democracy, and South Africa regained Liberal Democracy status. Kenya, Nigeria, and Indonesia sit in V-Dem's "grey zone" near a category boundary; this page uses V-Dem's best-estimate category for each. These are static classifications — V-Dem publishes no live API — refreshed by hand from the source reports rather than fetched at page load.

Female labour force participation (% of female population ages 15+, modeled ILO estimate) is fetched live, in your browser, from the World Bank Indicators API (SL.TLF.CACT.FE.ZS) each time this page loads — see the fetchLiveParticipation() function in this page's source. If that request fails or is blocked by your network, the chart and table fall back to the reference snapshot bundled in data.csv, and the banner above says so.

To point this at a different question entirely, replace data.csv — columns: country, iso3, region, regime_type, female_labor_force_participation — and swap the World Bank indicator code in the fetch call for another (wage gap, access to credit, entrepreneurship rate) to explore a different dimension of economic inclusion.
